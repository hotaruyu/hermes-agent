# LLM Wiki

## 定義
LLM Wiki とは、LLM が継続的に保守・更新する Markdown ベースの知識庫。
毎回ゼロから検索して答えるのではなく、既存知識をページとして蓄積し続ける。

## 核心
- 知識を都度再構成するのではなく、先に整理して残す
- 新しい資料が来たら、既存ページを更新する
- ページ同士をリンクして、論点・人物・概念をつなぐ
- 要約だけでなく、矛盾や未解決点も残す

## 3層構造
### 1. Raw sources
記事、PDF、会話メモ、画像などの元資料。

### 2. Wiki
テーマ、人物、概念、時系列を整理したページ群。

### 3. Index / Logs / Support files
索引、更新履歴、運用テンプレート、補助ファイル。

## この方式が向く場面
- 長期調査
- 読書メモ
- 個人の学習蓄積
- AI/事業/競合の継続観測
- チーム知識の整理
- ChatGPT や GitHub Issue を中継点にした手動知識移送

## 良い状態
- 各ページに役割がある
- 関連ページへ自然に辿れる
- 新情報が来たとき、どこを更新すればよいか明確
- 出典が追える
