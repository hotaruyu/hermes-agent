## 要点
- 米国の急伸テーマは、AI agent / automation / Claude Code / 仕事で使うAI / 小規模事業者向けAI / 初心者・シニア向け導入に大別できる。
- 単なるツール紹介より、「実際に仕事が進む」「毎回の面倒が減る」「今からでも遅くない」と感じさせる動画が強い。
- Claude Code や agent はそのままでは難しく見えるため、昭和AI向けには「下書きしてくれるAI」「毎回の面倒を覚えてくれるAI」へ翻訳した方が伝わりやすい。
- 小さな会社・個人商店向け、初心者向け、シニア向けの実用文脈は、再生規模よりも登録者数比や刺さり方の濃さが目立つ。
- 不安を煽るより、「今からで大丈夫」「最後は人が確認する」と整理する導入設計が再利用しやすい。

## 重要な観察
### 米国トレンド
- AI agent 関連は「何者かの説明」「最初の作り方」「非エンジニアでも使える入口」まで含めて強い。
- Claude Code は収益化や開発文脈だけでなく、non-coder 向けの入口動画も伸び始めている。
- 小規模事業者向けのAI活用は、売上誇張よりも文章・返信・段取りの自動化に寄った実務テーマが反応を得ている。
- 初心者向け ChatGPT 実務動画は、ツール数を増やすより「メール・議事録・調べ物」のような限定用途で見せる方が安定している。
- 31〜90日補完枠では、AI for Seniors / everyday life 向けの動画が登録者数比で突出し、昭和AI向け翻案価値が高い。

### 昭和AI向けの翻訳
- `AI agent` は「勝手に動くAI」ではなく、「いつもの手順を覚えて下準備してくれるもの」と説明する。
- `small business` は「小さな会社」「個人商店」「夫婦経営」「1人社長」へ言い換えると当事者感が出る。
- `for seniors` は直訳せず、「60代から」「昭和世代でも」「今からで大丈夫」と置き換える方が自然。
- 視聴者不安は「難しそう」「情報漏えいが怖い」「自分には遅い」の3つに集約しやすく、動画では毎回この不安整理を入れる価値がある。

## 昭和AI向け企画の優先順位
1. 今からで大丈夫。60代から始めるChatGPTの最初の1日
2. AIエージェントって何？を「毎回の面倒を覚えてくれるAI」として説明する
3. 小さな会社・個人商店がまず使うAI 5選
4. ChatGPTで実際に仕事を進める。メール・議事録・調べ物の3本だけ
5. プログラミング不要。AIに「自分用の小さな道具」を作ってもらう
