## 要点
- 昭和AIは、40〜60代の昭和世代に向けて「人生・仕事の経験こそがAI時代の武器になる」と伝えるチャンネルである。
- 単なるAI操作解説ではなく、「経験は、まだ終わっていない」という前向きな立場を一貫して取る。
- 絶対に譲らない核は「恐怖心を好奇心に変える」「経験に勝る力なし」「ブリコラージュ」の3本柱。
- 最新ニュースや稼ぎ方を主軸にせず、学びとマインドのコミュニティとして位置づける。
- ブランド仕様は墨色・生成り・金、Noto Serif JP限定、和の意匠優先、顔出しなしで厳守する。
- ナレーション主体のため、専門語や聞き取りづらい語を避け、読み上げやすい台本整形を重視する。
- Notionの制作管理DBが進捗の正本であり、プロパティ仕様やステータス値に独自ルールがある。
- デザイン面では、量産型AIビジュアルを避け、PIL直描きや金継ぎ的な和の表現を重視する。

## 重要な主張
### プロジェクトの目的
- 昭和世代のAI不安をゼロにするのではなく、不安を持ったまま一歩試す姿勢を肯定する。
- 長年の仕事・人間関係・失敗・修羅場は、AI時代にこそ価値を持つと伝える。

### 3本柱
- 恐怖心を好奇心に変える
- 経験に勝る力なし
- ブリコラージュ

### ブランド / 言語ルール
- ロゴ表記は「昭和AI」
- Noto Serif JPのみ使用し、Noto Sans JPは禁止
- 「プロンプト」は「AIへの頼み方」と言い換える
- LLM / API / ハルシネーション / トークン / 高度な自動化は使わない
- 「知らないと損」「今すぐ稼げる」など不安煽りは禁止

### 台本ルール
- 起承転結で組み、結で3本柱を回収する
- 冒頭の伏線は結で必ず明示的に回収する
- 結論だけで終わらず、コピペできる一歩を添える
- 1本に概念を詰め込みすぎず、具体例は実務寄りに寄せる

### 制作 / 管理ルール
- Notion DBが進捗正本
- チェックボックス系は `__YES__` / `__NO__` の文字列で扱う
- ステータス値は固定6種のみ
- 番号採番は本編=整数、番宣=小数
- SQL的クエリは有料制限があるため data_source_url 指定検索で代替する

## デザイン面の学び
- 「光る手」「ワイヤーフレーム」系のAI画像は量産型・没個性に見えるため避ける
- コード描画(PIL)と和の具体物表現が有効
