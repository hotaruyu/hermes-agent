# Hermes / Claude 共有Wiki運用メモ

## 共有の前提
- 共有されるのは会話ではなく、Obsidian内のMarkdownファイル
- 正本はWikiファイルとNotion進捗DBで分かれる
- Hermesは実ファイル更新担当、Claudeは整理・下書き・提案担当として使いやすい

## Claudeへ渡すときの短い説明
- このフォルダを共有Wikiとして扱ってください
- 既存ページを読んで、重複を避けて更新案を出してください
- Source / Topic / Map / Log の構造は崩さないでください
- 昭和AIの3本柱に合うように企画解釈してください

## おすすめの受け渡し手順
1. Claudeに新資料の要点整理をさせる
2. ClaudeにMarkdown下書きを出させる
3. HermesがWiki実ファイルへ反映する
4. Hermesが `Ingestion Log` を更新する

## 迷ったら優先すること
- 新規ページ乱立より既存Topic更新
- 動画一覧より比較・示唆
- AIニュースより昭和世代向け翻訳
- 抽象論より次回に使える具体メモ
